
# Midterm Study Notes: Weeks 1–5

## Week 1: History of Text and Writing
- **Cuneiform:** One of the earliest writing systems, developed in Mesopotamia around 3000 BC. It used wedge-shaped marks pressed into clay tablets.
- **Number Systems:** Mesopotamians used a base-60 system, which influenced how we measure time today (60 seconds and 60 minutes).
- **Printing Press:** Gutenberg's movable-type printing system helped make books easier to reproduce and information more accessible.

## Week 2: Representing Text and Numbers
- **Bits and Bytes:** A bit represents either 0 or 1, while a byte consists of 8 bits. One byte can represent 256 different values.
- **Computer Memory:** RAM is volatile memory that loses information when power is turned off. SSDs and HDDs provide non-volatile storage.
- **ASCII:** A character encoding system that assigns numerical values to letters, numbers, and symbols. For example, uppercase A is represented by 65.

## Week 3: Structure of Text
- **Markdown:** A lightweight markup language used to format plain text. `#` creates headings, `**text**` creates bold text, and `-` creates bullet points.
- **HTML:** Hypertext Markup Language structures web pages using tags such as `<h1>` for headings and `<p>` for paragraphs.
- **JSON:** A text-based format for storing structured data using objects with key-value pairs and arrays containing lists of values.

## Week 4: Manipulating Text and Text Editors
- **Text Editors vs. Word Processors:** Text editors work with plain text and are used for writing code, while word processors focus on formatted documents.
- **Keyboard Shortcuts:** `Ctrl+C` copies, `Ctrl+V` pastes, and `Ctrl+Z` undoes an action. Shortcuts improve efficiency.
- **Integrated Development Environments (IDEs):** Software that combines a text editor with programming tools such as debugging, code completion, and version control.

## Week 5: Command Line Interfaces
- **Command Line Interface (CLI):** Allows users to interact with computers by typing commands instead of using graphical menus.
- **Basic Commands:** `ls` lists files, `pwd` shows the current directory, `cd` changes directories, and `mkdir` creates a new directory.
- **SSH (Secure Shell):** Allows users to securely connect to remote computers through an encrypted connection.
